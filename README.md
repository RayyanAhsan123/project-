## 🚀 Quick Start

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Get a FREE Groq API key
Go to [https://console.groq.com](https://console.groq.com) → Sign up → Create API Key (it's free)

### 3. Run the app
```bash
streamlit run app.py
```

### 4. In the app
1. Paste your Groq API key in the top bar
2. Go to **Dataset & Model** tab → click **Load Dataset & Train Models**
3. Explore all 6 tabs

## 📦 Dataset

- **Primary**: NSL-KDD Training Set — auto-downloaded from [GitHub/defcom17](https://github.com/defcom17/NSL_KDD)
- **Fallback**: Realistic synthetic NSL-KDD (if no internet)
- **Kaggle link**: [NSL-KDD Dataset on Kaggle](https://www.kaggle.com/datasets/hassan06/nslkdd)

### NSL-KDD Attack Families
| Family | Examples |
|---|---|
| **DoS** | Neptune, Smurf, Back, Teardrop, Pod, Land |
| **Probe** | Portsweep, IPsweep, Satan, Nmap |
| **R2L** | Guess_passwd, FTP_write, Imap, Warezmaster |
| **U2R** | Buffer_overflow, Rootkit, Loadmodule, Perl |

## 🏗️ Architecture

```
NSL-KDD Dataset
     │
     ▼
Preprocessing (LabelEncoder + StandardScaler)
     │
     ├──► Random Forest Classifier  (binary: attack / normal)
     │         └── Accuracy, F1, Confusion Matrix
     │
     ├──► Isolation Forest          (unsupervised anomaly score)
     │
     └──► Snort Rule Simulation     (signature-based baseline)
              │
              ▼
         Packet Summaries
              │
              ▼
    RAG Knowledge Base lookup
              │
              ▼
    Groq LLaMA-3 70B → Structured Threat Report
              │
              ▼
    Groq LLaMA-3 8B  → SOC NLP Summary
```
